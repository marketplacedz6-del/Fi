# 🛍️ Elegance Home & Style — إليغانس هوم أند ستايل

متجر إلكتروني عربي كامل (عطور منزلية + أزياء) يعمل على **الاستضافة المجانية GitHub Pages** مع ربط لحظي بجداول **Google Sheets**، ويدعم **الدفع عند الاستلام (COD)** والتوصيل لجميع **الولايات الـ 58**.

---

## ✨ المميزات

### الواجهة الأمامية (Mobile-First)
- 🏠 صفحة رئيسية: شريط إعلاني (Hero) قابل للتغيير من لوحة التحكم (صورة أو فيديو)، أقسام "عطور المنزل" و"الأزياء"، و3 كاروسيلات: **وصل حديثاً / الأكثر مبيعاً / عروض خاصة**.
- 🎨 صفحة المنتج بنظام متغيرات متقدم:
  - **الأزياء**: اختيار اللون + المقاس، مع تغيّر صورة المنتج وسعره تلقائياً.
  - **عطور المنزل**: اختيار السعة (50ml / 100ml…) مع تغيّر السعر.
  - معرض صور مع تكبير (Zoom) وسحب باللمس + فيديو قصير اختياري.
  - زر "أضف إلى السلة" **ثابت أسفل الشاشة** في الهاتف.
  - اقتراحات "منتجات ذات صلة" (عطور مع أزياء والعكس).
- 📝 صفحة إتمام طلب في صفحة واحدة (Guest Checkout بدون حساب):
  - الاسم + رقم الهاتف (تحقق من الصيغة الجزائرية 05/06/07).
  - قائمة **58 ولاية** + قائمة البلديات المرتبطة بكل ولاية (~1580 بلدية).
  - خيارا توصيل تفاعليان: **باب المنزل** أو **المكتب/نقطة الاستلام** بأسعار مختلفة حسب الولاية، مع تحديث الإجمالي لحظياً.
  - كوبونات خصم (نسبة % أو مبلغ ثابت).
- 💵 الدفع عند الاستلام (COD) في كل الولايات.

### الربط مع Google Sheets
- ⚡ **تصدير لحظي**: بمجرد تأكيد العميل للطلب يُضاف صف جديد فوراً في جدول `Orders` بالأعمدة المطلوبة:
  `تاريخ الطلب | توقيت الطلب | رقم الطلب | اسم العميل | رقم الهاتف | الولاية | البلدية | المنتجات المطلوبة [مع المقاس/اللون/الحجم] | الكمية | إجمالي مبلغ المنتجات | تكلفة الشحن | نوع الشحن [منزل/مكتب] | المبلغ الإجمالي | حالة الطلب`
- 🔄 **تحديث الحالة من الجدول**: غيّر "حالة الطلب" مباشرة في Google Sheets (مثلاً إلى "تم الشحن") وستظهر التغييرات تلقائياً في لوحة التحكم (الجدول هو قاعدة البيانات).

### لوحة التحكم (admin.html)
- 🔐 دخول بالبريد الإلكتروني وكلمة السر (الافتراضي: `walid@gmail.com` / `2009` — يُغيَّر من الإعدادات ← الأمان).
- 🚚 **مصفوفة الشحن**: سعران لكل ولاية من الـ 58 (منزل/مكتب) + شحن مجاني للولاية أو فوق مبلغ معين + قيم افتراضية.
- 🛍️ **المنتجات والمخزون**: SKU لكل متغير، مخزون لكل (لون/مقاس/سعة)، "نفد من المخزون" تلقائي، تسعير مزدوج (سعر قديم مشطوب)، رفع صور يُضغط تلقائياً إلى **WebP**.
- 📦 **الطلبات**: فرز وتصفية (تاريخ / ولاية / حالة)، تغيير الحالة (قيد المراجعة، تم التأكيد، تم الشحن، تم التسليم، ملغى، مرتجع)، تصدير CSV:
  - تصدير كامل بكل الأعمدة.
  - **تصدير بوليصات جاهز لشركات التوصيل** (الاسم، الهاتف، الولاية، البلدية، العنوان، نوع التوصيل، قيمة الطلب…).
- 🎟️ **كوبونات الخصم**: نسبة % أو مبلغ ثابت + تاريخ انتهاء + حد أقصى للاستعمال.
- 📊 لوحة قيادة: عدد الطلبات، المبيعات، قيد المراجعة، طلبات اليوم.

### التتبع والأداء
- 📈 حقن أكواد **Meta Pixel / TikTok Pixel / Google Analytics** من لوحة التحكم (تُحقن في `<head>` تلقائياً).
- 🎯 أحداث قياسية: `ViewContent` (صفحة المنتج)، `AddToCart` (إضافة للسلة)، `Purchase` (يُطلق فقط في صفحة "شكراً" بقيمة الطلب الفعلية).
- ⚡ تحميل كسول للصور + كل الصور **WebP** + خط Cairo بنظام swap → فتح سريع على الهاتف.

## 🚀 طريقة التشغيل على GitHub Pages (مجاناً)

1. **ارفع المشروع إلى GitHub** (أو استعمل هذا المستودع):
   - `Settings ← Pages ← Source: Deploy from a branch ← main ← / (root) ← Save`
   - خلال دقيقة سيكون المتجر حياً على: `https://<your-username>.github.io/<repo>/`
2. افتح `admin.html` وسجّل الدخول:
   - **البريد الإلكتروني:** `walid@gmail.com`
   - **كلمة السر:** `2009`
3. **غيّر كلمة السر فوراً** من: الإعدادات ← الأمان.

> ⚠️ قبل الربط مع Google Sheets يعمل المتجر في **وضع تجريبي** (البيانات محفوظة في متصفحك فقط).

## 🔌 الربط مع Google Sheets (خطوة بخطوة)

1. أنشئ **Google Sheets** جديداً (أو استعمل جدولاً فارغاً).
2. من الجدول: **الامتدادات ← Apps Script**، احذف الكود الموجود والصق محتوى ملف [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
3. انشر: **Deploy ← New deployment ← Web app**:
   - Execute as: **Me** (أنت)
   - Who has access: **Anyone** (أي شخص)
   - انسخ **Web app URL**.
4. افتح الرابط وأضف في آخره `?action=init` — ستظهر صفحة تؤكد إنشاء الجداول وتعطيك **الرمز السري (Token)**.
5. في لوحة التحكم: **الإعدادات ← Google Sheets**، الصق الرابط + الرمز السري ثم **حفظ كل الإعدادات**.
6. ✅ من الآن: الطلبات تصل لحظياً لجدول `Orders`، والمنتجات والشحن والكوبونات تُقرأ من الجداول.

> 💡 لتحديث حالة طلب يدوياً: عدّل عمود "حالة الطلب" في الجدول ثم اضغط "تحديث من Google Sheets" في لوحة التحكم.

### هيكل الجداول التي يُنشئها `?action=init`
| الجدول | المحتوى |
|---|---|
| `Orders` | الطلبات (18 عموداً، الأعمدة الـ 14 الأولى كما في المواصفات) |
| `Products` | id \| name \| json (كامل بيانات المنتج) |
| `Shipping` | wilaya_id \| home \| desk \| free \| freeOver (58 صفاً) |
| `Coupons` | id \| code \| json |
| `Settings` | key \| value (الإعدادات، الرمز السري، تسلسل الطلبات…) |

## 🖼️ رفع الصور من لوحة التحكم

- تُرفع الصور من: المنتجات ← تعديل ← صور، أو من الإعدادات ← الشريط الإعلاني.
- تُضغط **تلقائياً إلى WebP** في المتصفح ثم تُرفع إلى **Google Drive** (حساب صاحب الجدول) برابط عام — لا حاجة لأي استضافة أخرى.
- يمكن ربط كل صورة بلون (لتغيير صورة المنتج عند اختيار اللون).

## 🔧 تخصيص سريع

- **الاسم والشعار والأرقام**: لوحة التحكم ← الإعدادات ← المتجر.
- **الشريط الإعلاني**: الإعدادات ← الشريط الإعلاني (صورة/فيديو + نصوص + زر).
- **أسعار الشحن الافتراضية**: لوحة التحكم ← مصفوفة الشحن.
- **المنتجات الافتراضية**: `assets/data/seed.json` (تُستعمل فقط قبل الربط أو كاحتياط).

## 🔒 ملاحظات أمان

- بيانات الدخول (البريد + كلمة السر) تُخزَّن مجزّأة (SHA-256) في إعدادات المتجر — **غيّر كلمة السر الافتراضية** بعد أول دخول، ولا تضع بيانات حساسة أخرى في المتصفح (طبيعة الاستضافة المجانية الثابتة).
- الرمز السري لـ Apps Script يتحكم بعمليات الإدارة فقط؛ إنشاء الطلبات من الزبائن مفتوح (مع حماية بسيطة من السبام).
