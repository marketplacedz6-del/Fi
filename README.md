# 🛍️ Elegance Home & Style — إليغانس هوم أند ستايل

متجر إلكتروني عربي كامل (عطور منزلية + أزياء نسائية) يعمل على **الاستضافة المجانية GitHub Pages**، وقاعدة بياناته هي **Firebase (Firestore + Storage + Auth)**، مع **ربط اختياري بجداول Google Sheets** لتصدير الطلبات بالأعمدة المطلوبة، ويدعم **الدفع عند الاستلام (COD)** والتوصيل لجميع **الولايات الـ 58**.

---

## ✨ المميزات

### الواجهة الأمامية (Mobile-First)
- 🏠 صفحة رئيسية: شريط إعلاني (Hero) قابل للتغيير من لوحة التحكم، أقسام "عطور المنزل" و"الأزياء"، و3 كاروسيلات: **وصل حديثاً / الأكثر مبيعاً / عروض خاصة**.
- 🎨 صفحة المنتج بنظام متغيرات:
  - **الأزياء**: اختيار اللون + المقاس، مع تغيّر صورة المنتج وسعره تلقائياً.
  - **عطور المنزل**: اختيار السعة (50ml / 100ml…) مع تغيّر السعر.
  - معرض صور مع تكبير + سحب باللمس، و**فيديو قصير اختياري** لكل منتج.
  - زر "أضف إلى السلة" ثابت أسفل الشاشة في الهاتف + اقتراحات منتجات ذات صلة.
- 📝 صفحة إتمام الطلب (بدون حساب):
  - **الاسم واللقب كل منهما في حقل مستقل** + رقم الهاتف 1 ورقم هاتف 2 احتياطي.
  - قائمة **58 ولاية** + البلديات المرتبطة بكل ولاية.
  - خيارا توصيل: **باب المنزل** أو **المكتب/نقطة الاستلام** بأسعار مختلفة، مع تحديث الإجمالي لحظياً.
  - كوبونات خصم (نسبة % أو مبلغ ثابت).
- 💵 الدفع عند الاستلام (COD) في كل الولايات.

### قاعدة البيانات — Firebase
- 🔥 **Firestore** يخزّن: المنتجات، الطلبات، أسعار الشحن (58 ولاية)، الكوبونات، والإعدادات.
- 🖼️ **Storage** لرفع صور المنتجات والشعار والهيرو (تُضغط تلقائياً إلى WebP ثم تُرفع).
- 🔐 **Authentication** للدخول إلى لوحة التحكم (البريد + كلمة السر).

### لوحة التحكم (admin.html)
- 📊 **لوحة القيادة**: إجمالي الطلبات، المبيعات، قيد المراجعة، طلبات اليوم + **المنتجات الأكثر مبيعاً**.
- 🛍️ **المنتجات**: إضافة/تعديل/حذف، رفع صور متعددة، رابط فيديو، متغيرات (لون/مقاس/سعة)، مخزون، تسعير مزدوج (سعر قديم مشطوب)، SKU.
- 🚚 **مصفوفة الشحن**: سعران لكل ولاية من الـ 58 (منزل/مكتب) + شحن مجاني فوق مبلغ معين.
- 📦 **الطلبات**: فرز (الأحدث ← الأقدم والعكس)، فلترة (حالة/ولاية/تاريخ/بحث)، تغيير الحالة (قيد المراجعة، تم التأكيد، تم الشحن، تم التسليم، ملغى، مرتجع)، تصدير CSV كامل أو بوليصات شركات التوصيل.
- ⚙️ **الإعدادات**: اسم المتجر، الشعار، الهاتف، **واتساب**، روابط **فيسبوك/انستغرام/تيك توك**، **أكواد Meta Pixel و TikTok Pixel و Google Analytics**، الشريط الإعلاني، وإعدادات الدخول.

### الربط مع Google Sheets (اختياري)
بمجرد تأكيد العميل للطلب يُضاف **صف لكل منتج** في جدول `Orders` بالأعمدة المطلوبة:

```
Order ID | Date | First Name | Last Name | Phone 1 | Phone 2 | Wilaya | Commune |
Delivery Type | Address | Product SKU | Product Name | Quantity | Unit Price (DZD) |
Total Amount (DZD) | Confirmation | Notes
```

## 🚀 التشغيل على GitHub Pages (مجاناً)

1. ارفع المشروع إلى GitHub (أو استعمل هذا المستودع).
2. `Settings ← Pages ← Source: Deploy from a branch ← main ← / (root) ← Save`.
3. خلال دقيقة سيكون المتجر حياً على: `https://<username>.github.io/<repo>/`.

## 🔥 إعداد Firebase (مرة واحدة)

> يستخدم المشروع مشروع Firebase المُعدّ أصلاً: `marketplace-dz-f2732`. يجب فقط تفعيل الخدمات الثلاث وتطبيق القواعد.

1. افتح [Firebase Console](https://console.firebase.google.com) → اختر مشروع **marketplace-dz-f2732** (أو أنشئ مشروعك وضع بياناته في `assets/js/config.js`).
2. **Firestore Database**: أنشئ قاعدة بيانات (Production mode، أي موقع). من تبويب **Rules** الصق محتوى ملف [`firestore.rules`](firestore.rules) ثم **Publish**.
3. **Authentication**: من **Sign-in method** فعّل **Email/Password**.
4. **Storage**: ابدأ التخزين، ومن **Rules** الصق محتوى ملف [`storage.rules`](storage.rules) ثم **Publish**.
5. افتح صفحة `admin.html` في متصفحك، اضغط **"👤 لا تملك حساباً؟ أنشئ حساب المدير"**، أدخل بريدك وكلمة سر قوية، ثم **إنشاء الحساب**. سيتم تسجيل دخولك تلقائياً.
6. من قسم **المنتجات** اضغط **"📥 استيراد منتجات تجريبية"** لتعبئة 14 منتجاً في Firebase (أو أضف منتجاتك مباشرة).

> 🔑 احتفظ بكلمة سر لوحة التحكم في مكان آمن. لتغييرها لاحقاً: الإعدادات ← الأمان.

## 📤 تفعيل تصدير الطلبات إلى Google Sheets

1. أنشئ **Google Sheets** جديداً (أو استعمل جدولاً فارغاً).
2. من الجدول: **الامتدادات ← Apps Script**، احذف الكود الموجود والصق محتوى ملف [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
3. انشر: **Deploy ← New deployment ← Web app**:
   - Execute as: **Me** (أنت)
   - Who has access: **Anyone** (أي شخص)
   - انسخ **Web app URL**.
4. افتح الرابط وأضف في آخره `?action=init` — ستظهر صفحة تؤكد إنشاء جدول **Orders** بالأعمدة المطلوبة.
5. في لوحة التحكم: **الإعدادات ← Google Sheets**، الصق الرابط ثم **حفظ كل الإعدادات**.
6. ✅ من الآن: كل طلب جديد يُضاف تلقائياً (صف لكل منتج) في الجدول.
